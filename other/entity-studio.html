Put it in the game

  1. Press Download .js (or Copy the file) and save it as entities/hall-thing.js
  2. Open entities/loader.js and add this line to the list, before 'core/phobia-finish.js': 
        'hall-thing.js',
  3. Reload the game. The creature is in the level studio's "who is in it" list, so a level can spawn it.
