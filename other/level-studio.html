How to put this level in the game

  1. Press Download (or copy the text) and save the file as levels/base/my-level-1.js
  2. Open levels/packs.js, find your pack's files: [ list and add this line: 
    'my-level-1.js',
  3. Reload the game. The level appears at the end of that pack.
